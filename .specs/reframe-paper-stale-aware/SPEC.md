## Why this paper (reality check)

The ICREC paper as-is would be rejected at e-Energy: thin related work (9 refs), incremental
contribution ("we optimized thresholds"), a fragile "to the best of our knowledge" novelty
claim, and methodological holes (checkpoint time of 148.8 s taken from a 7B model applied to
a 671B model; un-sourced idle power; only the 2×-overhead operating point).

The committed experiment data contains a genuinely novel story that we must **extract and
extend**:

1. **Noise is irrelevant; staleness is the enemy.** At 5-min resolution, CI is a near-unit-root
   process (lag-1 ≈ 0.9997). One-step forecast error (σ\*) costs < 5 % of savings (even 4σ\*
   keeps ≥ 93 % in DE/IT). A 6 h-stale decision costs 36–60 % of savings. This
   noise-vs-staleness decomposition is absent from the carbon-aware scheduling literature.
2. **Persistence ≈ AR(1) ≈ AR(7)** at every horizon (RMSE gap ≤ 0.2 % of RMSE). ML forecasters
   add nothing at 5-min granularity — a useful negative result.
3. **The optimizer responds to noise by widening the hysteresis margin** (DE margin 4.6 →
   28.4 g/kWh at 2σ\*). This is the seed of the paper's algorithmic contribution.

### Framing / thesis

Carbon-aware LLM pretraining does not need ML forecasting at 5-min scale. The binding
constraint is forecast **staleness**, not forecast **noise**. We introduce the **grace
horizon** (max decision staleness for ≤ 10 % savings loss) as a design parameter, show it is
predicted by the AR(1) prediction-interval width, and give a **stale-aware adaptive
controller** that widens the hysteresis margin with decision staleness and recovers most of
the loss. Result: simple, deployable, forecast-agnostic design rules for grid-flexible LLM
pretraining, framed as demand-side flexibility.

  0.92 % / 1.36 % / 3.30 %; lag-1 = 0.9997 / 0.9987 / 0.9960; AR(1) φ = 0.99965 / 0.99868 /

  IT 16.25 → 23.2 → 30.2; SE stays ≤ 0.7. Margin rule fails DE/IT ≥ 1σ\* additive; survives
  all delay cases and all SE additive.

## Known errors in ICREC version to NOT repeat

- False claim: "margin rule survives all delay levels in all regions" — false for IT delay=1
  (margin stays at 16.25 baseline, seedFraction 0).
- SE fixed-policy control used rounded thresholds (19,18) with a non-optimal start date
  (S₀=22.87 % / 99.4 % overhead) ≠ the reopt optimum (18.18, 17.51 → 23.17 % / 106.3 %).
- "Gap never exceeds ≈ 0.05 g/kWh" — actually 0.0512 at IT h=72; phrase as "≈ 0.05… ≤ 0.06".
